# 명령어

**목표: 일반 플레이어가 외울 명령어는 세 개.** 나머지는 GUI, 블록 상호작용, 바닐라 명령으로 한다.

한국어 별칭을 함께 등록하지만 마인크래프트 채팅의 한글 입력이 불편한 환경이 있어 영문 명령을 기본으로 안내한다.

## 1. 일반 플레이어

| 명령 | 별칭 | 모드 | 하는 일 |
|---|---|---|---|
| `/n` | `/국가` | simpleNationWar | 국가 GUI: 국가 정보, 국민 목록, 영토 지도(점령·해제), 국고, 관계, 거점, 연구 |
| `/info [플레이어]` | `/정보` | simpleNationWar | 정보 카드. 대상은 마크 이름 또는 커스텀 닉네임(자동완성에 둘 다 나옴). 생략하면 자기 자신 |
| `/g <메시지>` | `/전체` | simpleNationWar | 전체 채팅. 그냥 치는 채팅은 국가 채팅이라, 서버 전체에 말할 때만 쓴다 |

명령어 없이 하는 것:

| 하는 일 | 방법 |
|---|---|
| 국가 채팅 | 그냥 채팅. 국가 = 바닐라 팀 (아래 '채팅') |
| 스타포스 강화 | 대장장이 작업대를 웅크리고 우클릭 (zomApo) |
| 감염 레벨 확인 | 경계를 넘을 때 액션바, `/n` 첫 화면, 웹 지도 |
| 망자 위치 | 사망 직후 액션바 방향·거리 표시 |
| 디스코드 계정 연동 | 처음 접속할 때 화면에 뜨는 코드를 디스코드에 입력 |
| 상호평가 | 디스코드 DM (인게임 다이얼로그는 선택) |

couriersRoost 의 `/birds`, `/birdtrack` 은 운영자 권한 명령이다(일반 플레이어에게 안 보임).

### 채팅

**그냥 치는 채팅은 국가 채팅, 전체 채팅은 `/g <메시지>` 로만.** 국가 안 대화가 기본이고, 다른 국가에 들리게 말하려면 한 번 더 마음먹어야 한다.

| 상황 | 그냥 채팅 | `/g <메시지>` |
|---|---|---|
| 국가 있음 | 국가 채팅(같은 국가 접속자에게만) | 전체 채팅 |
| 국가 없음(팀 확정 전, 운영자) | 전체 채팅 | 전체 채팅 |
| couriersRoost 있음 | 국가 채팅을 **전서구**로 배달 | 전체 채팅을 **전서구**로 배달. `global_chat_cooldown` 이 `/g` 에 걸린다(운영자 제외) |
| couriersRoost 없음 | 바닐라 팀 채팅과 같은 모양 | 바닐라 전체 채팅 |

- 국가 채팅은 바닐라 `/teammsg` 의 전송부를 그대로 부른다. 서명된 메시지(보안 채팅 표시)가 유지되고, couriersRoost 가 그 전송부에 걸어 둔 믹스인이 전서구 배달로 바꾼다. 바닐라 `/tm <메시지>` 도 그대로 된다.
- couriersRoost 는 모든 일반 채팅을 전체 전서구로 보내려 한다. simpleNationWar 는 Fabric 채팅 이벤트(`ALLOW_CHAT_MESSAGE`)의 **기본 단계보다 앞선 단계**에서 먼저 받아 국가 채팅으로 돌리고 취소한다. `/g` 는 일반 채팅과 같은 방송 경로로 넘기므로 couriersRoost 가 평소처럼 전체 전서구로 처리한다.
- 접속 시 회색 한 줄 안내: "채팅은 국가 채팅으로 나가요. 전체 채팅은 /g <메시지>".
- 국가 채팅을 쳤는데 같은 국가 접속자가 없으면 "지금 접속한 국민이 없어요. 전체 채팅은 /g <메시지>" 를 띄운다(같은 사람에게 5분에 한 번). 시뮬레이션상 플레이 시간의 63~78% 는 같은 국가 사람이 없는 시간이라 자주 뜰 수 있다.
- 설정 `config/snw.properties` 의 `chat.default`: `team`(기본) 또는 `global`(바닐라처럼 전체 기본, 국가 채팅은 `/tm`).
- 디스코드 연동은 이 설정과 관계없이 채팅을 중계하지 않는다([mod.md](../discord/mod.md)).

## 2. 운영자 (권한 레벨 3 이상)

### simpleNationWar `/snw`

| 명령 | 하는 일 |
|---|---|
| `/snw reload` | 설정 다시 읽기 |
| `/snw nation <국가> rename <이름>` | 국가 이름 지정 |
| `/snw nation <국가> leader <플레이어>` | 원수 지정 |
| `/snw member <플레이어> set <국가>` / `clear` | 강제 배정·해제 |
| `/snw transfer open <시간>` | 이적 창 열기 |
| `/snw claim <국가> add\|remove [반경]` | 영토 수동 조정 |
| `/snw relation <국가> <국가> <중립\|동맹\|적대>` | 관계 강제 설정 |
| `/snw landmark <거점> owner <국가\|없음>` | 거점 소유 지정 |
| `/snw war window start\|stop` | 거점전 시간 수동 시작·종료 |
| `/snw stats <플레이어> reset` | 통계 초기화(사고 처리용) |

### zomApo `/zomapo`

| 명령 | 하는 일 |
|---|---|
| `/zomapo reload` | 설정 다시 읽기 |
| `/zomapo level get\|set\|clear` | 감염 레벨 조회·덮어쓰기 |
| `/zomapo bloodmoon start\|stop` | 블러드문 수동 진행 |
| `/zomapo nest spawn` | 감염 둥지 생성 |
| `/zomapo stats <플레이어>` | 좀비 통계 조회 |
| `/zomapo debug spawn <변종>` | 변종 소환 |

### snw-discord `/snwd`

| 명령 | 하는 일 |
|---|---|
| `/snwd status` | 봇 연결 상태 |
| `/snwd reload` | 설정 다시 읽기 |
| `/snwd resync` | 연동 목록·닉네임 다시 받기 |

## 3. 디스코드 (봇 슬래시 명령)

| 명령 | 대상 | 하는 일 |
|---|---|---|
| `/정보 [유저]` | 모두 | 인게임 `/info` 와 같은 카드 |
| `/닉네임 변경` | 모두 | 닉네임 변경 신청(시즌 중 1회, 운영자 승인) |
| `/평가 시작\|현황\|종료\|결과` | 관리자 | 상호평가 라운드 관리 |
| `/팀 편성\|확정` | 관리자 | 균형 편성안 생성, 확정 시 국가 역할·채널 생성 |
| `/서버 상태\|공지` | 관리자 | 서버 상태 조회, 공지 송출 |

가입·닉네임 등록·계정 연동은 명령이 아니라 **버튼과 모달**로 한다([bot.md](../discord/bot.md)).
