# K/D/A

플레이어 객체마다 **K(다른 플레이어를 죽인 횟수), D(죽은 횟수), A(다른 플레이어의 죽음에 관여한 횟수, 직접 죽인 것 제외)** 를 저장한다. 인게임에는 **K 와 KDA** 만 보여 준다.

```
KDA = (K + A) / max(D, 1)
```

D 가 0 이면 1 로 나눈다(K + A 를 그대로 표시). 소수점 둘째 자리까지.

좀비 처치 수·좀비 스코어는 zomApo 가 기록한다([stats.md](https://github.com/menonng/zomApo/blob/HEAD/docs/design/stats.md)).

## 1. 판정

### K (킬)

- 다른 플레이어가 죽을 때 **처치 크레딧**을 가진 플레이어에게 +1.
- 처치 크레딧은 바닐라 규칙을 따른다: 마지막으로 피해를 준 플레이어(직접 타격, 투사체 소유자, 점화한 TNT, 길들인 늑대의 주인). 플레이어에게 맞은 뒤 5초 안에 낙하·용암·공허로 죽어도 그 플레이어의 킬이다.
- **세지 않는 경우**
  - 자살, 자기 TNT
  - 같은 국가 국민을 죽인 경우 (별도 `teamKills` 에만 기록)
  - 같은 상대를 10분 안에 3번째 이상 죽인 경우 (친구끼리 킬 쌓기 방지. 사망은 정상 기록)
  - 망자 좀비 처치

### D (데스)

- **모든 사망**을 센다(좀비·환경·PvP). 요구 사항의 정의를 그대로 따른다.
- PvP 로 죽은 횟수는 `deathsPvp` 로 따로 저장한다.

### A (어시스트)

- 피해자가 죽기 전 **15초 안에** 피해를 준 다른 플레이어. 킬러는 제외.
- 사망 한 번에 한 사람당 한 번만.
- 최소 기여: 2.0 피해(하트 1칸) 이상 또는 피해자 최대 체력의 10% 이상. 툭 건드리고 어시스트를 챙기는 것을 막는다.
- 피해자와 같은 국가·동맹 국가 사람의 피해는 제외.
- 투사체·포션·늑대 피해도 소유자의 기여로 센다.

## 2. 표시

| 위치 | 표시 |
|---|---|
| `/info` 카드 | `K 12   KDA 1.84` |
| `/info` 카드에 마우스를 올리면 | `K 12 / D 9 / A 5`, `PvP 기준 KDA 3.40 (PvP 사망 5)`, 아군 사살 0 |
| 국가 GUI 국민 목록 | 머리 아이콘 설명에 K·KDA |
| 디스코드 `/정보` | 같은 카드 |

### PvP 기준 KDA 를 함께 보여 주는 이유

D 에 좀비·환경 사망이 모두 들어가면 KDA 는 PvP 실력보다 **생존력** 지표가 된다. 시뮬레이션에서 핵심 유저의 시즌 KDA 는 전체 사망 기준 0.8~1.0, PvP 사망만 셀 때 1.7~1.9 로 두 배 가까이 차이 났다(시즌 PvP 킬은 1인당 5~6회 수준). 원래 정의대로 표시하되, 마우스를 올리면 PvP 기준 값도 보이게 한다. 설정 `kda.deaths = ALL | PVP` 로 표시 기준을 바꿀 수 있다.

## 3. 저장

`SavedData` `snw_players` 에 UUID 별로.

```json
{
  "uuid": "…",
  "kills": 12,
  "deaths": 9,
  "deathsPvp": 5,
  "assists": 5,
  "teamKills": 0,
  "recentVictims": { "<uuid>": [1736420000, 1736420300] },
  "log": [
    { "t": 1736420300, "type": "kill", "victim": "<uuid>", "assists": ["<uuid>"], "where": "overworld", "x": 812, "z": -340 }
  ]
}
```

- `log` 는 시즌 결산·분쟁 확인용 원장이다. 좌표는 운영자와 결산에만 쓰고 공개하지 않는다.
- 피해 기여 추적은 메모리에만 둔다(피해자별 최근 15초 피해 목록). 서버 재시작 중에 걸친 기여는 버린다.

## 4. 이벤트

K/D/A 가 바뀔 때 `snw-api` 이벤트(`onPlayerKill`)를 낸다. 디스코드 모드가 이를 받아 킬 피드를 보낸다. 킬 피드에는 좌표를 넣지 않는다.
