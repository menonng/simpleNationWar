# UI

바닐라 클라이언트가 그릴 수 있는 것만 쓴다: **상자 메뉴 GUI**, **바닐라 다이얼로그**(입력 폼), 채팅 컴포넌트(마우스 올림·클릭), 액션바, 보스바, 타이틀.

## 1. 색

사용자 팔레트를 따르되 남발하지 않는다. 의미가 정해진 곳에만 색을 쓰고 나머지는 바닐라 기본색(흰색·회색).

| 용도 | 색 |
|---|---|
| 1국 / 2국 / 3국 | 빨강 `#FF0045` / 파랑 `#3355BB` / 노랑 `#FFCC11` |
| 감염 Lv1~2 / Lv3~4 / Lv5 | 초록 `#55BB44` / 보라 `#660099` / 빨강 `#FF0045` |
| 강화 별(채움) | 노랑 `#FFCC11` |
| 긍정 알림(점령 완료, 방어 성공) | 하늘 `#39C5BB` |
| 경고(적대 선언, 블러드문) | 주황 `#FF7E00`, 블러드문 보스바는 빨강 |
| 칭호 | 분홍 `#FFB4CC` |

보스바는 바닐라 색 7종만 되므로 가장 가까운 색(빨강·파랑·노랑·초록·보라·분홍·흰색)을 쓴다.

## 2. `/n` 국가 GUI (상자 6줄)

```
┌───────────────────────────────────────────┐
│ [국가 깃발]  1국 · 원수 철수 · 국민 5명     │  1줄: 국가 요약 (감염 레벨, 영토 54/79)
│ [국민] [영토] [국고] [관계] [거점] [연구]   │  2줄: 탭 버튼
│                                           │
│            (선택한 탭의 내용)               │  3~6줄
│                                           │
└───────────────────────────────────────────┘
```

### 2-1. 국민 탭 (국가전쟁 플레이어 목록)

- 국민 한 명 = 플레이어 머리 아이콘 한 칸. 접속 중이면 반짝임(인첸트 효과 덮어쓰기), 아니면 일반.
- 아이콘 이름: `닉네임` (국가 색)
- 아이콘 설명:

```
Steve123                       ← 마크 이름 (회색)
간부 · 접속 중 / 3시간 전
K 12   KDA 1.84
좀비 처치 1,284   좀비 스코어 2,391
이번 주 플레이 9시간
```

- 정렬: 접속 중 → 직위 → 최근 접속.
- 원수가 아이콘을 클릭하면 직위 변경 다이얼로그.

### 2-2. 영토 탭

- 9 × 4 칸 = 플레이어 주변 청크 격자. 가운데가 현재 청크.
- 칸 아이템: 자국 영토 = 국가 색 유리판, 동맹 = 하늘 유리판, 다른 국가 = 해당 국가 색 유리판, 빈 땅 = 감염 레벨별 색 유리판(초록·보라·빨강) 또는 흰 유리판, 거점·캠프 = 표지 아이템.
- 클릭: 점령 / 우클릭(간부 이상): 해제. 조건이 안 되면 설명에 이유 표시.
- 아래 줄: 화살표로 격자 이동, 영토 수 `54 / 79`.

### 2-3. 국고 탭

- 54칸 공용 창고는 별도 상자 화면으로 연다. 자국 영토 밖이면 잠김 표시.
- 원수·간부에게는 '기록' 버튼(최근 넣기·꺼내기 50건).

### 2-4. 관계 탭

- 다른 두 국가의 깃발 + 현재 관계(중립·동맹·적대), 남은 휴전 시간.
- 원수만 제안·수락·선언 버튼이 활성화.

### 2-5. 거점 탭

- 거점 4곳: 소유국 깃발, 소유 시간, 다음 거점전까지 남은 시간, 오늘 보상 수령 여부.

### 2-6. 연구 탭

- 서버 공동 연구 3단계를 가로로. 완료 = 하늘색, 진행 중 = 노랑, 잠김 = 회색.
- 진행 중 단계를 누르면 조건 목록과 진행도(서버 전체), '손에 든 아이템 납품' / '국고에서 납품' 버튼.
- 아래 줄: 국가별 기여 막대(국가 색)와 우리 국가 기여 상위 3명. 지역 표본 3종의 보유·필요 수량.

## 3. `/info` 정보 카드 (채팅)

```
━━━━━━━━━━━━━━━━━━━━
 철수  Steve123
 [1국] 간부 · 학살자
 K 12   KDA 1.84
 좀비 처치 1,284   좀비 스코어 2,391
━━━━━━━━━━━━━━━━━━━━
```

- 닉네임은 국가 색, 마크 이름은 회색, 칭호는 분홍.
- KDA 에 마우스를 올리면 D·A·PvP 기준 KDA, 좀비 스코어에 마우스를 올리면 변종별 처치 수와 최고 강화 성.
- 다른 모드가 `snw:stat_provider` 로 줄을 추가할 수 있다(zomApo 의 좀비 줄이 이렇게 들어온다).

## 4. 다이얼로그 (바닐라 입력 폼)

| 쓰는 곳 | 입력 |
|---|---|
| 직위 변경 | 선택지(간부·국민) |
| 관계 제안·적대 선언 확인 | 확인/취소 + 사유 텍스트(선택) |
| 국고 대량 인출 확인 | 확인/취소 |
| 상호평가(인게임, 선택) | 대상별 5개 항목 각각 1~5 선택 |

## 5. 액션바·보스바·타이틀

| 표시 | 내용 |
|---|---|
| 액션바 | 영토 경계 진입 `[1국] 영토` / `야생 · 감염 Lv3`, 망자 방향·거리 |
| 보스바 | 거점전 점령 진행, 블러드문, 알파 좀비 체력 |
| 타이틀 | 거점 점령, 블러드문 10분 전 예고·시작, 공동 연구 단계 완료 |
