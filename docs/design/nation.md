# 국가 시스템

## 1. 원칙

> 시즌은 2027-01-16 ~ 2027-02-07(23일). 이 문서의 일·시간은 모두 현실 시간이다.

- 국가는 **집단 형성 장치**다. 함께 정착하고, 함께 지키고, 비동기로라도 함께 무언가를 쌓게 한다.
- 시뮬레이션상 플레이 시간의 63~78% 는 같은 국가 사람이 아무도 없을 때다(zomApo [simulation.md](https://github.com/menonng/zomApo/blob/HEAD/docs/server/simulation.md)). 그래서 **국고·국가 프로젝트 같은 비동기 협동**과 **국가 간 상호작용**(동맹, 거점전, 공동 이벤트)을 함께 둔다.
- **오프라인 약탈은 불가능하다.** 영토 블록 보호는 어떤 관계에서도 풀리지 않는다.
- 명령어는 `/n` 하나로 모으고 나머지는 GUI 로 한다.

## 2. 국가

| 항목 | 값 |
|---|---|
| 개수 | 3개 고정 (설정 파일에서 정의, 시즌 중 생성·삭제 없음) |
| 이름 | 팀 확정 후 국민 투표로 정하고 운영자가 입력. 그 전까지 `1국`·`2국`·`3국` |
| 색 | 빨강 `#FF0045`, 파랑 `#3355BB`, 노랑 `#FFCC11` |
| 깃발 | 국가별 현수막 패턴 (수도 깃발·지도 아이콘·GUI 아이콘) |

초록 `#55BB44` 과 보라 `#660099` 는 좀비·감염 표시 전용으로 남겨 둔다.

### 2-1. 바닐라 팀으로 표현

국가마다 바닐라 스코어보드 팀 `snw_<국가id>` 를 만든다. 서버 사이드만으로 많은 것이 해결된다.

| 바닐라 팀 기능 | 쓰임 |
|---|---|
| 팀 색 | 머리 위 이름 색. 레거시 16색만 되므로 가장 가까운 색(빨강 → `red`, 파랑 → `blue`, 노랑 → `yellow`) |
| 접두사 | `[국가명] ` 을 **정확한 국가 색(16진)** 으로 탭 목록·채팅에 표시 |
| 아군 피해 끔 | 국민끼리 PvP 불가 |
| 투명한 아군 보기 | 투명 포션을 쓴 국민이 반투명하게 보임 |
| 팀 채팅(`/teammsg`) | **국가 채팅**. 그냥 치는 채팅이 국가 채팅으로 나가고, 전체 채팅은 `/g` 로만([commands.md](commands.md) '채팅') |

## 3. 소속

- 시즌 시작 전: 디스코드 봇의 상호평가 → 팀장(원수) 3명 → **국가 추첨식**(별점 + 참여도 가중 추첨, 단짝 묶음, 보이지 않는 재추첨 가드) → 24시간 맞교환 → 확정([peer-rating.md](../discord/peer-rating.md) 5절).
- 확정된 소속은 봇이 모드에 내려보내고, 첫 접속 시 자동으로 국가에 들어간다.
- 시즌 중 이적은 원칙적으로 불가. 국가 간 '최근 72시간 활동 국민 수' 차이가 2명 이상으로 72시간 넘게 이어지면 운영자가 이적 창(24시간)을 연다. 이적은 본인 신청 + 양쪽 원수 동의.
- 운영자 명령으로 강제 배정·해제 가능.

## 5. 수도와 영토

### 5-1. 수도

- 개장 시 국가마다 정해진 출발지([decisions.md](https://github.com/menonng/zomApo/blob/HEAD/docs/server/decisions.md) 2번)에 **수도 깃발**(국가 현수막 + 보호 블록)을 둔다. 깃발이 있는 청크가 수도 청크.
- 수도 청크를 중심으로 3×3 청크는 **핵심 구역**: 몹 폭발·굴착 피해를 아예 받지 않는다.
- 개장 후 72시간 안에 원수가 수도를 한 번 옮길 수 있다(출발지 반경 250블록 안, 다른 국가 수도에서 400블록 밖).
- 블러드문 방어 판정은 수도 깃발이 무사한지로 한다(zomApo).

### 5-2. 점령

- `/n` → **영토 지도**(9 × 5 청크 격자, 플레이어 위치 중심)에서 빈 청크를 클릭하면 점령, 간부 이상이 우클릭하면 해제.
- 조건
  - 기존 영토와 변으로 맞닿아 있을 것 (전초기지 예외)
  - 다른 국가 영토에서 2청크 이상 떨어질 것
  - 생존자 캠프·거점 구역이 아닐 것
  - 영토 상한 이하일 것
- 유지비 없음.

### 5-3. 영토 상한

```
상한 = 24 + 6 × 국민 수 + floor( √(국가 좀비 스코어 합) / 2 ) + 8 × 보유 거점 수
```

| 예 (국민 5명) | 상한 |
|---|---|
| 개장 직후 (스코어 0) | 54 청크 |
| 스코어 2,500 | 79 청크 |
| 스코어 10,000, 거점 1곳 | 112 청크 |

zomApo 가 없으면 스코어 항은 0. 상한이 줄어들어도 이미 점령한 청크는 유지되고 새 점령만 막힌다.

### 5-4. 전초기지

- 국가당 최대 2개, 각 4청크 이하. 본토와 연결되지 않아도 된다.
- 다른 국가 영토에서 8청크 이상 떨어져야 한다.
- 용도: 먼 광산, 네더 포탈 주변, 거점 근처 전진 기지.

## 7. 관계

| 관계 | 성립 | 효과 |
|---|---|---|
| 중립 | 기본값 | 상대 영토에서 PvP 불가, 야생 PvP 가능 |
| 동맹 | 양쪽 원수 수락. **국가당 1개까지** | 어디서든 서로 PvP 불가, 문·버튼 사용 가능, 결속 인첸트 적용, 로케이터 바 공유(선택) |
| 적대 | 한쪽 원수 선언, **12시간 뒤 발효**(예고) | 상대 영토 안에서도 PvP 가능. 블록 보호는 그대로 |

- 적대 해제·동맹 성립 같은 '개선'은 양쪽 동의, 동맹 파기·적대 선언 같은 '악화'는 한쪽 결정(Towns and Nations 와 같은 원칙).
- 적대를 풀면 72시간 동안 다시 적대할 수 없다.
- **2:1 고착 방지**: 두 국가가 동맹이고 한 국가가 고립되면, 고립 국가는 거점전 점령 속도 ×1.25. 동맹은 한 국가당 하나뿐이라 셋이 모두 묶일 수는 없다.

## 8. 거점전

Towns and Nations 의 랜드마크 + 존재 기반 점령을 가져오되, 영토 정복은 뺐다.

### 8-1. 거점

| 거점 | 위치 | 특징 |
|---|---|---|
| 접경 거점 ×3 | 두 수도 사이 중간 지점 근처(수도에서 약 700블록. 수도 사이 약 1,390블록, 월드보더 반경 2,000) | 국가 쌍마다 하나. 마주치기 쉬운 자리 |
| 심층 거점 ×1 | 보더 근처 고지대 폐허 | 감염 레벨 +1, 보상이 크다 |

- 바닐라 블록으로 지은 폐허 구조물. 점령 구역은 중심 반경 8블록.
- 감염 레벨은 주변 + 1.0(zomApo).

### 8-2. 점령 규칙

| 항목 | 규칙 |
|---|---|
| 시간 | **매주 목 21:00 ~ 22:00, 일 20:00 ~ 21:00** (설정). 그 밖에는 소유권이 바뀌지 않는다. 3주 시즌에 약 6회 |
| 점령 | 점령 구역 안에 다른 국가보다 많은 인원이 있으면 진행. 누적 5분이면 점령 |
| 분쟁 | 인원이 같거나 소유국이 더 많으면 진행 정지(보스바 '분쟁 중') |
| 좀비 | 거점전 시간 동안 점령 구역 주변에 좀비가 계속 몰려온다(PvPvE) |
| 소유국 부재 | 소유국 접속자가 없어도 점령 가능. 시간이 미리 공지되므로 |
| 동맹 | 동맹 국민은 인원 수에 함께 센다. 소유권은 한 국가에만 |
| PvP | 거점전 시간 동안 거점 반경 32블록 안에서는 관계와 무관하게 PvP 허용(동맹끼리 제외). 블록 보호는 그대로 |

### 8-3. 보상

- 매일 06:00 거점 상자에 자원(철·금·다이아 확률, 바이러스 결정)이 채워진다. 소유국 국민만 연다.
- 영토 상한 +8.
- 소유국은 그 거점 주변에서 나오는 지역 표본을 더 쉽게 얻는다(치료제 재료).

## 9. 국고와 국가 프로젝트

### 9-1. 국고

- 국가 공용 창고 54칸(가상 인벤토리). `/n` → 국고. **자국 영토 안에서만** 열린다(물류의 의미를 남긴다).
- 넣기·꺼내기 기록이 남고 원수·간부가 볼 수 있다.
- 서로 접속 시간이 달라도 물자를 주고받을 수 있게 하는 핵심 장치다.
- **칸 해금(선택)**: 처음엔 27칸만 열리고, 거점 첫 점령·다른 지역 표본 첫 확보·공동 연구 기여 1위 달성 같은 국가의 '발견'마다 9칸씩 열린다. 잠긴 칸은 방벽 아이템과 해금 조건으로 표시. monun 의 inv-captive(공유 인벤토리를 서버 공동 발견으로 한 칸씩 해금)에서 가져온 생각으로, 비동기 협동에 작은 목표를 더한다.

### 9-2. 백신 조각 현황 (치료제 엔딩 분기)

> 치료제는 게이지 없는 '백신 조각 엔딩 분기'로 줄였다(zomApo [decisions.md](https://github.com/menonng/zomApo/blob/HEAD/docs/server/decisions.md) 4-5). `/n` 연구 탭은 서버 전체 백신 조각 수와 우리 국가가 모은 수만 보여 준다. 아래는 이전 공동 연구안의 기록이다.

#### (기록) 공동 프로젝트안

> 처음에는 국가별 레이스였지만, 시뮬레이션에서 '플레이 시간 1위 국가가 91~100% 우승'으로 나와 **서버 공동 연구 + 국가 기여 순위**로 바꾸는 것을 제안한다. 검토 문서: zomApo [bloodmoon-and-cure.md](https://github.com/menonng/zomApo/blob/HEAD/docs/design/bloodmoon-and-cure.md) 2절.

- `/n` → 연구 탭. **서버 전체가 함께 채우는** 3단계 게이지와 조건, 그리고 국가별·개인별 기여 순위를 보여 준다.
- 아이템은 국고 또는 손에서 바로 납품한다. 아무 때나, 누구나. 납품한 사람과 국가에 기여가 쌓인다.
- 지역 표본(국가 출발지 주변에서만 나오는 치료제 재료)은 다른 국가와 교역해야 모두 모인다. 생존자 캠프의 교환함을 쓴다.
- 통계 조건(변종 처치, 둥지 파괴, 블러드문 방어 등)은 zomApo 가 `snw-api` 의 조건 제공자로 등록한다. simpleNationWar 는 프로젝트 틀(게이지, 납품, 기여 집계)만 제공한다.
- 기여 1위 국가는 시즌 종료 시 '구원자의 나라' 칭호.

## 10. 로케이터 바 국가 필터

바닐라 로케이터 바(게임룰로 켬)는 기본적으로 모든 플레이어를 보여 준다. 서버에서 웨이포인트 전송을 걸러 **같은 국가 국민(선택: 동맹)만** 보이게 한다. 클라이언트 모드 없이 "우리 국민이 어느 쪽에 있는지"를 알 수 있어 함께 움직이기 쉬워진다.

구현 시 26.3 jar 에서 웨이포인트 추적 클래스를 확인한다. 여의치 않으면 국민에게만 보이는 방향 표시를 액션바로 대신한다.

## 11. 생존자 캠프

- 월드 중앙 반경 64블록. 월드 스폰, 보호 구역(PvP·건축 불가, 적대 몹 스폰 없음, 감염 레벨 0).
- 공용 게시판(표지판), 국가별 안내판, 최후의 호드 이벤트 무대.

## 12. 주민 상한

- 국가당 주민 12명(설정). 자국 영토 청크 안의 주민을 센다.
- 상한을 넘으면 가장 최근에 들어온 주민부터 '피난민' 표시(이름표)와 거래 잠금.
- 영토 안에서 주민 번식이 일어나지 않는다.
