## 국가

### 1. 원칙

> 시즌은 2027-01-16 ~ 2027-02-07(23일). 이 문서의 일·시간은 모두 현실 시간이다.

- 국가는 **집단 형성 장치**다. 함께 정착하고, 함께 지키고, 비동기로라도 함께 무언가를 쌓게 한다.
- 시뮬레이션상 플레이 시간의 63~78% 는 같은 국가 사람이 아무도 없을 때다(zomApo [simulation.md](https://github.com/menonng/zomApo/blob/HEAD/docs/server/simulation.md)). 그래서 **국고·국가 프로젝트 같은 비동기 협동**과 **국가 간 상호작용**(동맹, 거점전, 공동 이벤트)을 함께 둔다.
- **약탈은 전면 허용한다**(2026-11-22 개정). 다른 국가 영토에서도 블록 설치·파괴·상자 열기가 되고, 아무도 접속하지 않은 나라도 털릴 수 있다. 영토 안에서도 PvP 가 된다. 영토는 '우리 땅'(감염 레벨·국고·국가 코어)의 표시이지 보호막이 아니다.
- 명령어는 `/n` 하나로 모으고 나머지는 GUI 로 한다.

초록 `#55BB44` 과 보라 `#660099` 는 좀비·감염 표시 전용으로 남겨 둔다.

#### 2-1. 바닐라 팀으로 표현

국가마다 바닐라 스코어보드 팀 `snw_<국가id>` 를 만든다. 서버 사이드만으로 많은 것이 해결된다.

| 바닐라 팀 기능 | 쓰임 |
|---|---|
| 팀 색 | 머리 위 이름 색. 레거시 16색만 되므로 가장 가까운 색(빨강 → `red`, 파랑 → `blue`, 노랑 → `yellow`) |
| 접두사 | `[국가명] ` 을 **정확한 국가 색(16진)** 으로 탭 목록·채팅에 표시 |
| 아군 피해 **켬**(2026-11-22) | 같은 국가끼리도 싸울 수 있다. **같은 국가 사람에게 죽으면 그 자리에서 바로 부활하고 소지품·경험치를 그대로 지닌다**(인벤세이브, 망자·드랍 없음, K/D 에 넣지 않음) |
| 투명한 아군 보기 | 투명 포션을 쓴 국민이 반투명하게 보임 |
| 팀 채팅(`/teammsg`) | **국가 채팅**. 그냥 치는 채팅이 국가 채팅으로 나가고, 전체 채팅은 `/g` 로만([nation.md](#명령어) '채팅') |

### 3. 소속

- 시즌 시작 전: 디스코드 봇의 상호평가 → 팀장(원수) 3명 → **국가 추첨식**(별점 + 참여도 가중 추첨, 단짝 묶음, 보이지 않는 재추첨 가드) → 24시간 맞교환 → 확정([peer-rating.md](../discord/peer-rating.md) 5절).
- 확정된 소속은 봇이 모드에 내려보내고, 첫 접속 시 자동으로 국가에 들어간다.
- 시즌 중 이적은 원칙적으로 불가. 국가 간 '최근 72시간 활동 국민 수'(잠수 제외, 15절) 차이가 2명 이상으로 72시간 넘게 이어지면 운영자가 이적 창(24시간)을 연다. 이적은 본인 신청 + 양쪽 원수 동의.
- 운영자 명령으로 강제 배정·해제 가능.

#### 3-1. 국가 스폰 지점과 시즌 시작

| 항목 | 규칙 |
|---|---|
| 국가 스폰 지점 | 국가마다 하나. **(0, 0) 에서 1,000블록 이상 3,000블록 미만** 고리 안. 세 지점은 서로 1,500블록 이상, 중심에서 본 각도 차 90° 이상, 중심 거리 차 400블록 이내(공정성). 시드 탐색 도구가 고르고 운영자가 `/snw spawn set` 으로 넣는다. 판정: `logic` 의 `NationSpawn.validate` |
| 시즌 시작 전 | 모두 중앙 생존자 캠프(대기실). 모험 모드, 피해·허기 없음 |
| 시즌 시작 | 운영자 `/snw season start` → 국가에 따라 **모두 각자 국가 스폰 지점 주변으로 이동**, 서바이벌 모드, 게임룰 설정(`locator_bar false` 등), 시즌 시계·감염 램프(zomApo) 시작 |
| 개인 스폰 지점 | 국가 스폰 지점에서 **40~60블록** 떨어진 무작위 땅 위(넓이에 고르게 뽑음). 물·용암·나뭇잎 위·선인장 옆·발밑이 빈 곳·다른 국가 영토는 피한다. 48번 안에 못 찾으면 국가 스폰 지점. 시즌 시작 때 한 번 정해 저장한다. 판정: `PersonalSpawn.pick`. **이 자리가 그 플레이어의 바닐라 리스폰 지점**이다(플레이어마다 따로 정해지는 '스폰'. 시즌 시작 때 국가 텔레포트와 함께 정한다) |
| 리스폰 | 침대·리스폰 정박기가 있으면 바닐라대로, 없으면 개인 스폰 지점 |
| 늦게 온 사람 | 시즌 시작 뒤 처음 접속하면 바로 개인 스폰 지점으로. 배정·보급은 3-2 |
| 수도 이전 | 개장 72시간 안 1회(후보지 반경 250블록 안). 국가 스폰 지점이 옮겨지고 국민 개인 스폰 지점도 다시 정한다 |
| 이적 | 새 국가 기준으로 개인 스폰 지점을 다시 정한다 |

#### 3-2. 늦게 합류하는 사람 (2026-11-21)

코드: `logic` 의 `join/LateJoin.kt`.

| 경우 | 처리 |
|---|---|
| 국가 추첨 뒤에 새로 들어온 사람 | **본인이 고른다**(2026-11-22 확정). 처음 접속하면 국가 선택 창이 뜨고, 국가마다 이름·색·원수·국민 수·최근 72시간 활동 국민 수(잠수 제외)를 보여 준다. 고르기 전에는 생존자 캠프(모험 모드)에 머문다. 창을 닫으면 다음 접속 때 다시 뜬다. 디스코드에 알리고, 운영자가 바꿀 수 있다 |
| 한 국가로 몰릴 때 | 운영자가 `LateJoin.assign`(활동 국민이 가장 적은 국가) 기준으로 옮길 수 있다. 자동 배정은 하지 않는다 |
| 시즌 시작 3일째 이후 **처음** 접속 | '늦깎이 보급 상자' 한 번(아래). 이미 접속한 적 있는 사람(복귀자)은 받지 않는다 |
| 처음 접속한 뒤 플레이 30분 | 좀비 떼 대상에서 빠진다(zomApo). 블러드문·일반 좀비는 그대로 |

| 처음 접속한 날 | 늦깎이 보급 상자 (마법부여 없음) |
|---|---|
| 0~2일째 | 없음(모두와 같은 출발) |
| 3~7일째 | 돌 도구 4종, 빵 16, 횃불 16, 침대, 붕대 4 |
| 8~14일째 | 철 곡괭이·도끼·검, 돌 삽, 방패, 구운 소고기 24, 횃불 32, 침대, 붕대 6, 해독제 1 |
| 15일째~ | 위 + 철 갑옷 한 벌, 활, 화살 32 |

- 그 시점 기존 국민의 평균 장비보다 한 단계 아래로 잡았다. 따라잡는 데 드는 시간을 줄일 뿐 앞지르게 하지는 않는다.
- 붕대·해독제는 zomApo 의 아이템(플레이어 시스템 '상처').

### 5. 수도와 영토

#### 5-1. 수도와 국가 코어 (2026-11-22 개정)

- 개장 시 국가마다 정해진 출발지([decisions.md](https://github.com/menonng/zomApo/blob/HEAD/docs/server/decisions.md) 2번)에 **국가 코어**를 둔다. 코어가 있는 청크가 수도 청크.
- **국가 코어 = 신호기 블록**(국가 색 유리로 빛기둥 색을 낸다). 블록으로는 부서지지 않고 대신 **체력**이 있다.  코드: `logic` 의 `core/NationCore.kt`(피해·빈집·회복 계산).

| 항목 | 규칙 |
|---|---|
| 체력 | **100,000** (2026-11-22: 1,000 → 100,000. 1,000 은 새벽에 4명이 몇 분 만에 끝냈다) |
| 받는 피해 | 공격 한 번에 **최대 2**(무기·인첸트·폭발과 상관없이 2 로 자른다). **적대 국가**(7절) 플레이어와 몬스터만 깎는다. 자국민·동맹·중립 국가 플레이어는 깎지 못한다 |
| 세는 공격 (2026-11-22, A안) | **공격 쿨다운이 90% 이상 찬 근접 공격만 2**, 덜 찬 공격은 0(막 클릭·매크로가 이득이 없게). **무기만 센다**: 검·도끼·철퇴·삼지창·창. 맨손이나 다른 물건으로 치면 0(맨손은 쿨다운이 짧아 초당 4 를 넣는 구멍이 된다). 원거리는 다 당긴 화살·석궁 화살·던진 삼지창. 같은 플레이어의 공격은 **0.5초에 한 번만** 센다(다중 발사·관통 화살로 한 번에 여러 번 넣지 못하게. 검 쿨다운 0.625초보다 짧아 검에는 영향이 없다). 폭발은 한 번 터질 때마다 2 |
| 무기 내구도 | **코어를 칠 때마다 반드시 닳는다.** 센 공격은 2, 덜 찬 공격도 1. 내구성 인첸트로 건너뛰지 않는다(수선은 평소대로 경험치로 고친다). 철 검 한 자루로 코어 체력 약 250, 다이아몬드 검 약 1,560, 네더라이트 검 약 2,030 을 깎는다 |
| 공성 시간 | **플레이어는 공성 시간대에만 코어를 깎을 수 있다**(기본 20:00~25:00, 서버가 활동 시간대를 보고 옮긴다, 5-1-2). 몬스터는 시간과 상관없이 깎는다 |
| 접속·부활 직후 | 보호(무적) 중인 플레이어의 공격은 코어에 0(16절) |
| 빈집 | **자국민이 아무도 접속해 있지 않으면 코어가 받는 피해가 절반**(2 → 1). 잠수 중인 국민도 접속으로 센다(지킬 수는 없어도 알림은 받는다). 몬스터 피해에도 같다 |
| 몬스터 | **몬스터의 어그로 대상이 될 수 있다**: 근처 좀비가 코어를 노리고 때린다(플레이어가 더 가까우면 플레이어 우선). 블러드문 좀비는 코어를 향해 온다 |
| 자국민 우클릭 | 국가 정보와 코어 정보 창: 국가 이름·원수·국민 수·영토(청크 수 / 상한), 코어 체력(예: 98,120 / 100,000)·회복까지 남은 시간·최근에 맞은 시각·지금 이 영토의 감염 레벨. 다른 국가 사람이 우클릭하면 국가 이름만 |
| 체력 0 일 때 | **국가 멸망**(5-1-1) |
| 회복 | **마지막으로 맞은 뒤 2시간이 지나면 시간당 10**씩 저절로(하루 최대 240). 맞으면 2시간을 다시 센다. **수리는 없다** |

**얼마나 버티나** (A안 기준): 플레이어 한 명이 검 쿨다운대로 치면 초당 약 3.2 가 최대다(도끼 약 1.6~2, 활 약 2). 쉬지 않고 칠 때 4명이면 약 2시간 10분, 자국민이 없는 새벽(빈집 절반)이면 약 4시간 20분, 8명이면 약 1시간 5분. 무기는 10만을 깎는 동안 네더라이트 검 약 49자루(철 검이면 약 400자루) 분량이 닳는다. 회복은 하루 240 이 최대라, 한 번 크게 깎인 코어는 시즌 내내 그 흔적이 남는다.

**체력 상향 검토 (2026-11-22) → 100,000 유지로 확정.** 공성 시간대(5-1-2)가 새벽 빈집털이를 막으므로 체력은 올리지 않는다. 아래는 검토 기록: 코어 피해는 회복이 거의 없어 **여러 날에 걸쳐 쌓인다**. 나눠 쳐도 회복이 하루 240 뿐이라 **합계 시간은 거의 같다**. 아래 시간은 모두 '쉬지 않고 친 합계'다(빈집 = 자국민이 아무도 없을 때, 피해 절반).

| 체력 | 4명 (자국민 접속 중) | 4명 빈집(새벽) | 8명 | 8명 빈집 | 검 소모(네더라이트 / 철, 빈집이면 두 배) |
|---|---|---|---|---|---|
| 100,000 (지금) | 2시간 10분 | 4시간 20분 | 1시간 5분 | 2시간 10분 | 49 / 400 |
| 200,000 | 4시간 20분 | 8시간 40분 | 2시간 10분 | 4시간 20분 | 98 / 800 |
| 300,000 | 6시간 30분 | 13시간 | 3시간 15분 | 6시간 30분 | 148 / 1,200 |
| 500,000 | 10시간 50분 | 21시간 40분 | 5시간 25분 | 10시간 50분 | 246 / 2,000 |

- (검토 당시 추천은 200,000 이었다. 공성 시간대 도입 뒤 100,000 으로 확정: 4명이 공성 시간 저녁 한두 번이면 무너지고, 지키는 쪽도 그 시간에 모인다.) 300,000 이상이면 멸망(5-1-1)이 사실상 일어나지 않아 적대 선언의 의미가 약해진다.
- 체력만 올리면 지루해질 수 있어, 공성 쪽에 '진행이 보이는 것'(코어 체력 단계별 빛기둥 색 변화, 디스코드 '코어 75%·50%·25%' 알림)을 함께 둔다.
- 인원이 많은 국가가 유리한 것은 체력으로 풀지 않는다(빈집 절반·휴전·동맹이 맡는다).

- 개장 후 72시간 안에 원수가 수도(코어)를 한 번 옮길 수 있다(출발지 반경 250블록 안, 다른 국가 수도에서 400블록 밖).
- 블러드문은 **세 수도에 동시에** 오고, 각 나라는 자기 **국가 코어**를 지킨다(이번 블러드문에서 코어가 체력 100 을 잃으면 그 나라는 실패. 깎인 체력은 실제로 빠진다). 30분 동안 휴전. 규칙 전체는 zomApo 좀비 문서 '감염 레벨' 6절이 기준이다.
- 예전의 '핵심 구역(몹 폭발·굴착 피해 없음)'과 자동 복구는 뺐다(6절).

#### 5-1-2. 공성 시간대 (2026-11-22)

새벽 빈집털이를 막으려고, 플레이어가 코어를 깎을 수 있는 시간을 사람이 가장 많은 저녁으로 묶는다. 코드: `logic` 의 `core/SiegeWindow.kt`.

| 항목 | 규칙 |
|---|---|
| 기본 | **20:00~25:00**(다음 날 01:00). 서버 현지 시각(KST) |
| 길이 | 5시간 고정 |
| 평일·주말 | 따로 정한다(토·일이 주말). 자정을 넘는 창은 시작한 날의 창을 따른다(금 20:00~토 01:00 는 평일 창) |
| 조사 | 서버가 시간별 평균 동시 접속(잠수 제외 인원 수만, 누가 접속했는지는 남기지 않는다)을 최근 14일 동안 평일·주말 따로 모은다 |
| 옮기기 | 매일 06:00 에 '동시 접속 합이 가장 큰 연속 5시간'을 고른다. 시작은 16~22시 중에서만(끝은 최대 다음 날 03:00). 지금 창보다 **10% 이상** 나을 때만 옮긴다. 표본이 평일 5일·주말 2일보다 적으면 기본값 |
| 알림 | 바뀐 창은 디스코드와 인게임으로 알리고 **24시간 뒤**부터 적용한다(공격·수비 모두 준비하게) |
| 표시 | 코어 정보 창과 `/info` 에 '오늘 공성 시간 20:00~01:00', 열리면 적대 관계 국민에게 액션바 한 줄 |
| 그 밖의 시간 | 적대 국민도 코어를 깎지 못한다. 약탈·영토 PvP 는 시간과 상관없이 그대로(6절) |

- 예(시뮬레이션 접속 곡선, 20명·활성 10명): 평일은 19시·20시 시작이 같아 20:00~25:00 그대로, 주말은 낮에 몰려 **16:00~21:00** 으로 옮긴다.
- 빈집 피해 절반은 그대로 둔다(공성 시간대에도 자국민이 아무도 없을 수 있다).
- 블러드문 휴전(30분)이 공성 시간대와 겹치면 휴전이 먼저다.

#### 5-1-1. 국가 멸망 (2026-11-22)

코어 체력이 0 이 되면 그 국가는 시즌 끝까지 사라지고, 국민은 다른 국가로 옮겨진다.

| 마지막 타격 | 국민이 옮겨 가는 곳 |
|---|---|
| 다른 국가 플레이어 | **그 플레이어의 국가** |
| 몬스터(좀비 등), 그리고 최근 1시간 안에 코어를 친 다른 국가가 있다 | **가장 최근에 코어를 친 국가** |
| 몬스터, 최근 1시간 안에 코어를 친 국가가 없다 | 국민마다 **남은 국가 중 활동 국민이 적은 쪽으로 자동 배정**(`LateJoin.assign`. 무소속은 두지 않는다: 영토·국고·스폰이 없어 서버에서 할 수 있는 일이 없어진다) |

- 옮겨진 국민은 새 국가의 일반 국민이 되고(원수·간부 직위는 사라진다), 개인 스폰 지점을 새 국가 기준으로 다시 정한다(3-1 '이적'과 같음). 소지품은 그대로.
- 멸망한 국가의 영토는 모두 풀려 야생이 되고, 거점 소유권도 풀린다. 국고 내용물은 국민을 받은 국가의 국고로 합치고(자동 배정이면 코어 자리에 보존 드랍), 동맹·적대 관계는 사라진다.
- 서버 전체 공지와 디스코드 알림. 생존일지에 '어느 나라가 무너졌다'로 남는다.

#### 5-2. 점령

- `/n` → **영토 지도**(9 × 5 청크 격자, 플레이어 위치 중심)에서 빈 청크를 클릭하면 점령, 간부 이상이 우클릭하면 해제.
- 조건
  - 기존 영토와 변으로 맞닿아 있을 것 (전초기지 예외)
  - 다른 국가 영토에서 2청크 이상 떨어질 것
  - 생존자 캠프·거점 구역이 아닐 것
  - 영토 상한 이하일 것
- 유지비 없음.

#### 5-3. 영토 상한

```
상한 = 24 + 6 × 국민 수 + floor( √(국가 좀비 스코어 합) / 3 ) + 8 × 보유 거점 수
```

2026-11-22 인원 상향(20±3명, 국가당 약 7명) 반영: 국가 좀비 스코어 합이 약 2.06배(√ 1.44배)로 커지므로 스코어 항의 나눗수를 2 → 3 으로 올려,
같은 시점의 스코어 항이 예전(5명 기준)과 비슷하게 머물게 했다. 국민 항(6 × 국민 수)은 그대로라 국민 1인당 땅은 조금 좁아진다(사람이 많을수록 붙어 산다).

| 예 (국민 7명) | 상한 |
|---|---|
| 개장 직후 (스코어 0) | 66 청크 |
| 스코어 5,150 | 89 청크 |
| 스코어 20,600, 거점 1곳 | 121 청크 |

zomApo 가 없으면 스코어 항은 0. 상한이 줄어들어도 이미 점령한 청크는 유지되고 새 점령만 막힌다.

#### 5-4. 전초기지

- 국가당 최대 2개, 각 4청크 이하. 본토와 연결되지 않아도 된다.
- 다른 국가 영토에서 8청크 이상 떨어져야 한다.
- 용도: 먼 광산, 네더 포탈 주변, 거점 근처 전진 기지.

### 7. 관계

| 관계 | 성립 | 효과 |
|---|---|---|
| 중립 | 기본값 | 어디서든 PvP 가능(2026-11-22: 영토 안 PvP 허용) |
| 동맹 | 양쪽 원수 수락. **국가당 1개까지** | 어디서든 서로 PvP 불가, 서로의 영토에서 짓고 열 수 있음, 결속 인첸트 적용 |
| 적대 | 한쪽 원수 선언, **12시간 뒤 발효**(예고) | **상대 국가 코어를 공격할 수 있다**(5-1). 영토 PvP·약탈은 중립과 같다. 즉 적대는 '그 나라를 무너뜨리겠다'는 선전포고이고, 12시간 예고 동안 상대가 지킬 준비를 한다 |

- 적대 해제·동맹 성립 같은 '개선'은 양쪽 동의, 동맹 파기·적대 선언 같은 '악화'는 한쪽 결정(Towns and Nations 와 같은 원칙).
- 적대를 풀면 72시간 동안 다시 적대할 수 없다.
- **2:1 고착 방지**: 두 국가가 동맹이고 한 국가가 고립되면, 고립 국가는 거점전 점령 속도 ×1.25. 동맹은 한 국가당 하나뿐이라 셋이 모두 묶일 수는 없다.

### 8. 거점전

Towns and Nations 의 랜드마크 + 존재 기반 점령을 가져오되, 영토 정복은 뺐다.

#### 8-1. 거점

| 거점 | 위치 | 특징 |
|---|---|---|
| 접경 거점 ×3 | 두 수도 사이 중간 지점 근처(수도에서 약 700블록. 수도 사이 약 1,390블록, 월드보더 반경 2,000) | 국가 쌍마다 하나. 마주치기 쉬운 자리 |
| 심층 거점 ×1 | 보더 근처 고지대 폐허 | 감염 레벨 +1, 보상이 크다 |

- 바닐라 블록으로 지은 폐허 구조물. 점령 구역은 중심 반경 8블록.
- 감염 레벨은 주변 + 1.0(zomApo).

#### 8-2. 점령 규칙

| 항목 | 규칙 |
|---|---|
| 시간 | **매주 목 21:00 ~ 22:00, 일 20:00 ~ 21:00** (설정). 그 밖에는 소유권이 바뀌지 않는다. 3주 시즌에 약 6회 |
| 점령 | 점령 구역 안에 다른 국가보다 많은 인원이 있으면 진행. 누적 5분이면 점령 |
| 분쟁 | 인원이 같거나 소유국이 더 많으면 진행 정지(보스바 '분쟁 중') |
| 좀비 | 거점전 시간 동안 점령 구역 주변에 좀비가 계속 몰려온다(PvPvE) |
| 소유국 부재 | 소유국 접속자가 없어도 점령 가능. 시간이 미리 공지되므로 |
| 동맹 | 동맹 국민은 인원 수에 함께 센다. 소유권은 한 국가에만 |
| PvP | 거점전 시간 동안 거점 반경 32블록 안에서는 관계와 무관하게 PvP 허용(동맹끼리 제외). 블록 보호는 그대로 |

#### 8-3. 보상

- 매일 06:00 거점 상자에 자원(철·금·다이아 확률, 바이러스 결정)이 채워진다. 소유국 국민만 연다.
- 영토 상한 +8.
- 소유국은 그 거점 주변에서 나오는 지역 표본을 더 쉽게 얻는다(치료제 재료).

### 9. 국고와 국가 프로젝트

#### 9-1. 국고

- 국가 공용 창고 54칸(가상 인벤토리). `/n` → 국고. **자국 영토 안에서만** 열린다(물류의 의미를 남긴다).
- 넣기·꺼내기 기록이 남고 원수·간부가 볼 수 있다.
- 서로 접속 시간이 달라도 물자를 주고받을 수 있게 하는 핵심 장치다.
- **칸 해금(선택)**: 처음엔 27칸만 열리고, 거점 첫 점령·백신 조각 첫 확보·블러드문 첫 방어 성공 같은 국가의 '발견'마다 9칸씩 열린다. 잠긴 칸은 방벽 아이템과 해금 조건으로 표시. monun 의 inv-captive(공유 인벤토리를 서버 공동 발견으로 한 칸씩 해금)에서 가져온 생각으로, 비동기 협동에 작은 목표를 더한다.

#### 9-2. 백신 조각 현황 (치료제 엔딩 분기)

> 치료제는 게이지 없는 '백신 조각 엔딩 분기'로 줄였다(zomApo [decisions.md](https://github.com/menonng/zomApo/blob/HEAD/docs/server/decisions.md) 4-5). `/n` 연구 탭은 서버 전체 백신 조각 수와 우리 국가가 모은 수만 보여 준다. 아래는 이전 공동 연구안의 기록이다.

##### (기록) 공동 프로젝트안

> 처음에는 국가별 레이스였지만, 시뮬레이션에서 '플레이 시간 1위 국가가 91~100% 우승'으로 나와 **서버 공동 연구 + 국가 기여 순위**로 바꾸는 것을 제안한다. 검토 문서: zomApo [bloodmoon-and-cure.md](https://github.com/menonng/zomApo/blob/HEAD/docs/design/bloodmoon-and-cure.md) 2절.

- `/n` → 연구 탭. **서버 전체가 함께 채우는** 3단계 게이지와 조건, 그리고 국가별·개인별 기여 순위를 보여 준다.
- 아이템은 국고 또는 손에서 바로 납품한다. 아무 때나, 누구나. 납품한 사람과 국가에 기여가 쌓인다.
- 지역 표본(국가 출발지 주변에서만 나오는 치료제 재료)은 다른 국가와 교역해야 모두 모인다. 생존자 캠프의 교환함을 쓴다.
- 통계 조건(변종 처치, 둥지 파괴, 블러드문 방어 등)은 zomApo 가 `snw-api` 의 조건 제공자로 등록한다. simpleNationWar 는 프로젝트 틀(게이지, 납품, 기여 집계)만 제공한다.
- 기여 1위 국가는 시즌 종료 시 '구원자의 나라' 칭호.

**주민 상한 = 한 국가의 영토 청크 안에서 '정주민'으로 일하는(거래·번식하는) 주민의 최대 수**다. 영토 안에 그보다 많이 있을 수는 있지만, 넘친 주민은 일하지 않는 '피난민'이 된다. 주민을 없애거나 막지는 않는다.

| 항목 | 규칙 |
|---|---|
| 세는 대상 | 자국 영토 청크 안의 주민(어른·아기 모두, 실업자 포함). 떠돌이 상인·좀비 주민은 세지 않는다 |
| 상한 | 국가당 20명(설정 `villager.cap`) |
| 정주민·피난민 | 영토에 **먼저 들어온 순서**로 20명까지 정주민, 그 뒤는 피난민. 피난민은 머리 위 이름표 '피난민', 거래 창을 열면 막히고 액션바에 이유, 번식에 끼지 않는다. 직업 블록·침대 차지는 바닐라대로 |
| 빈자리 | 정주민이 죽거나 영토 밖으로 나가면, 가장 먼저 들어온 피난민이 정주민이 된다(이름표가 사라짐) |
| 판정 | 10초마다, 그리고 주민이 영토 경계를 넘을 때 |

추가로 생기는 경우별 처리:

| 들어오는 길 | 처리 |
|---|---|
| 데려오기(끈·보트·광산 수레·걸어서) | 영토에 들어온 순간을 '들어온 시각'으로. 자리가 있으면 정주민, 없으면 피난민 |
| 좀비 주민 치료 | 치료된 순간이 들어온 시각. 자리 없으면 피난민 |
| 번식 | 정주민이 상한 미만이고 그 국가의 오늘 번식이 4마리 미만일 때만 아기가 생긴다(설정 `villager.breed_per_day`). 조건이 안 되면 하트가 떠도 아기가 생기지 않는다. 태어난 아기는 바로 정주민으로 센다 |
| 영토를 넓혀 마을을 품음 | 새 청크의 주민은 그 청크를 점령한 시각에 들어온 것으로. 넘치면 피난민 |
| 영토를 잃음 | 그 청크의 주민은 더 이상 세지 않는다(다른 나라 영토가 되면 그 나라 기준으로 다시 센다) |
| 다른 나라로 넘어감 | 그 나라 영토에 들어간 시각부터 그 나라 기준 |

- '오늘'은 현실 06:00 기준으로 바뀐다. 남은 번식 수와 정주민 수는 국가 GUI 1줄에 `주민 14/20 · 오늘 번식 2/4` 로 보인다.
- 영토 밖에 세워 두면 세지 않지만 보호(영토 규칙)도 받지 못한다. 좀비가 주민을 공격한다.
- 마을은 바닐라처럼 생긴다. 영토 밖 마을의 번식은 바닐라 그대로다.

### 1. 일반 플레이어

| 명령 | 별칭 | 모드 | 하는 일 |
|---|---|---|---|
| `/n` | `/국가` | simpleNationWar | 국가 GUI: 국가 정보, 국민 목록, 영토 지도(점령·해제), 국고, 관계, 거점, 연구 |

| 디스코드 계정 연동 | 처음 접속할 때 화면에 뜨는 코드를 디스코드에 입력 |

#### 채팅

**그냥 치는 채팅은 국가 채팅, 전체 채팅은 `/g <메시지>` 로만.** 국가 안 대화가 기본이고, 다른 국가에 들리게 말하려면 한 번 더 마음먹어야 한다.

| 상황 | 그냥 채팅 | `/g <메시지>` |
|---|---|---|
| 국가 있음 | 국가 채팅(같은 국가 접속자에게만) | 전체 채팅 |
| 국가 없음(팀 확정 전, 운영자) | 전체 채팅 | 전체 채팅 |
| couriersRoost 있음 | 국가 채팅을 **전서구**로 배달 | 전체 채팅을 **전서구**로 배달. `global_chat_cooldown` 이 `/g` 에 걸린다(운영자 제외) |
| couriersRoost 없음 | 바닐라 팀 채팅과 같은 모양 | 바닐라 전체 채팅 |

- 국가 채팅은 바닐라 `/teammsg` 의 전송부를 그대로 부른다. 서명된 메시지(보안 채팅 표시)가 유지되고, couriersRoost 가 그 전송부에 걸어 둔 믹스인이 전서구 배달로 바꾼다. 바닐라 `/tm <메시지>` 도 그대로 된다.
- couriersRoost 는 모든 일반 채팅을 전체 전서구로 보내려 한다. simpleNationWar 는 Fabric 채팅 이벤트(`ALLOW_CHAT_MESSAGE`)의 **기본 단계보다 앞선 단계**에서 먼저 받아 국가 채팅으로 돌리고 취소한다. `/g` 는 일반 채팅과 같은 방송 경로로 넘기므로 couriersRoost 가 평소처럼 전체 전서구로 처리한다.
- 접속 시 회색 한 줄 안내: "채팅은 국가 채팅으로 나갑니다. 전체 채팅은 /g <메시지>를 쓰십시오.".
- 국가 채팅을 쳤는데 같은 국가 접속자가 없으면 "지금 접속한 국민이 없습니다. 전체 채팅은 /g <메시지>를 쓰십시오." 를 띄운다(같은 사람에게 5분에 한 번). 시뮬레이션상 플레이 시간의 63~78% 는 같은 국가 사람이 없는 시간이라 자주 뜰 수 있다.
- 설정 `config/snw.properties` 의 `chat.default`: `team`(기본) 또는 `global`(바닐라처럼 전체 기본, 국가 채팅은 `/tm`).
- 디스코드 연동은 이 설정과 관계없이 채팅을 중계하지 않는다([README.md](../discord/README.md#연동-모드)).

### 3. `/info` 정보 창 (상자 창, 2026-11-21 3차)

하이픽셀 같은 큰 서버의 표준 방식: `/info` 를 치면 **상자 창**이 열리고, 플레이어 머리를 누르면 그 사람의 **정보 창**(또 하나의 상자 창)으로 들어간다. 바닐라 상자 화면이라 클라이언트 모드 없이 열린다. 창 안의 아이템은 꺼낼 수 없다(클릭·쉬프트 클릭·숫자키·드래그·더블 클릭 모으기·버리기 모두 막음). 코드: `mod` 의 `info/InfoMenus.kt`.

| 여는 법 | 열리는 창 |
|---|---|
| `/info` | **플레이어 목록** |
| `/info <이름>` | 그 사람 **정보 창**(닉네임·마크 이름 모두 됨) |
| 채팅에서 **닉네임을 클릭** | 그 사람 정보 창(채팅 이름에 `/info <이름>` 실행 클릭 이벤트) |
| `/n` 국민 탭에서 머리 아이콘 클릭 | 그 국민의 정보 창 |

#### 3-1. 플레이어 목록 (상자 6줄)

```
┌ 플레이어 정보 ──────────────────────────────────┐

│ [머리][머리][머리][머리][머리][머리][머리][머리][머리] │
│ [머리][머리][머리] …                               │  2~5줄: 플레이어 머리 36칸
│                                                  │
│                                                  │
│ [◀ 이전] ▒ ▒ ▒ [쪽 1/2] ▒ ▒ ▒ [다음 ▶]  [닫기]      │  6줄: 쪽 넘김, 닫기
└──────────────────────────────────────────────────┘
```

- 머리 = 그 사람 스킨의 플레이어 머리. 이름은 닉네임(국가 색), 설명은 아래처럼 짧게.

## 지도 연동

두 지도 모드를 모두 지원한다. 서버에는 둘 중 하나만 깔아도, 둘 다 깔아도 된다.

### 1. 구조

```
MapAdapter (인터페이스)
├─ BlueMapAdapter    BlueMap API (de.bluecolored:bluemap-api) — BlueMapAPI.onEnable 에서 등록
└─ SquaremapAdapter  squaremap API (xyz.jpenilla:squaremap-api) — SquaremapProvider.get()
```

- 어댑터는 해당 모드가 있을 때만 켠다(`FabricLoader.isModLoaded`). 지도 API 는 `compileOnly`.
- simpleNationWar 는 '무엇을 그릴지'(레이어·도형·색·팝업)를 지도 모드와 무관한 모델로 만들고, 어댑터가 각 API 로 옮긴다.
- zomApo 의 감염 레이어도 같은 `MapAdapter` 를 `snw-api` 로 받아 그린다(지도 코드를 두 번 만들지 않는다).

### 2. 레이어

|---|---|---|---|
| 국가 영토 | 국가 색 반투명(채움 25%) 다각형 + 테두리 | 켬 | 점령 변화 후 10초 디바운스 |

#### 영토 팝업

```

```

### 3. 청크 묶음 → 다각형

영토는 청크 집합이므로 그대로 그리면 마커가 수십~수백 개가 된다. 하나의 다각형(구멍 포함)으로 합친다.

1. 영토 청크마다 네 변을 만든다.
2. 이웃 청크와 공유하는 변(양쪽에서 반대 방향으로 나오는 변)은 지운다.
3. 남은 변을 꼭짓점으로 이어 닫힌 고리를 만든다.
4. 고리의 방향(넓이 부호)으로 바깥 경계와 구멍을 나누고, 구멍은 그것을 감싸는 바깥 경계에 붙인다.
5. 일직선 위의 중간 꼭짓점은 지운다.

BlueMap 은 `ShapeMarker`(구멍 지원) 또는 높이를 주는 `ExtrudeMarker`, squaremap 은 `MultiPolygon`(구멍 지원)으로 그린다. 전초기지처럼 떨어진 조각은 다각형 여러 개가 된다.

### 4. 공개 범위 설정

서버 결정은 zomApo [decisions.md](https://github.com/menonng/zomApo/blob/HEAD/docs/server/decisions.md) 3번(지형·영토·감염 공개, 실시간 위치·지하 비공개).

| 항목 | BlueMap | squaremap |
|---|---|---|
| 실시간 플레이어 위치 끄기 | 플레이어 마커 기능 끄기 | `player-tracker` 끄기 |
| 지하 숨기기 | 동굴 제거 설정(지표 아래 일정 깊이 렌더 안 함) | 지하 렌더 끔 |
| 네더 천장 | 천장 위 렌더 안 함 | 같음 |

정확한 설정 키는 각 모드의 26.4 대응 버전 설정 파일에서 확인한다.

### 5. 시즌 전체 지도 포스터

시즌 결산 때 지도 타일(squaremap 의 평면 타일, 또는 BlueMap 평면도)을 이어 붙여 한 장의 큰 이미지를 만들고, 그 위에 시즌 마지막 날의 영토 경계·거점 소유를 얹어 디스코드 명예의 전당에 올린다. monun 이 포크해 둔 dynmap-assemble(Dynmap 타일을 한 장으로 합치는 스크립트)과 같은 방식이다. 서버 밖에서 돌리는 작은 스크립트로 충분하다.

## KDA

플레이어 객체마다 **K(다른 플레이어를 죽인 횟수), D(죽은 횟수), A(다른 플레이어의 죽음에 관여한 횟수, 직접 죽인 것 제외)** 를 저장한다. 인게임에는 **K 와 KDA** 만 보여 준다.

```
KDA = (K + A) / max(D, 1)
```

D 가 0 이면 1 로 나눈다(K + A 를 그대로 표시). 소수점 둘째 자리까지.

좀비 처치 수·좀비 스코어는 zomApo 가 기록한다([player.md](https://github.com/menonng/zomApo/blob/HEAD/docs/design/player.md#좀비-통계)).

### 1. 판정

#### K (킬)

- 다른 플레이어가 죽을 때 **처치 크레딧**을 가진 플레이어에게 +1.
- 처치 크레딧은 바닐라 규칙을 따른다: 마지막으로 피해를 준 플레이어(직접 타격, 투사체 소유자, 점화한 TNT, 길들인 늑대의 주인). 플레이어에게 맞은 뒤 5초 안에 낙하·용암·공허로 죽어도 그 플레이어의 킬이다.
- **세지 않는 경우**
  - 자살, 자기 TNT
  - 같은 국가 국민을 죽인 경우 (별도 `teamKills` 에만 기록)
  - 같은 상대를 10분 안에 3번째 이상 죽인 경우 (친구끼리 킬 쌓기 방지. 사망은 정상 기록)
  - 망자 좀비 처치

#### D (데스)

- **모든 사망**을 센다(좀비·환경·PvP). 요구 사항의 정의를 그대로 따른다.
- PvP 로 죽은 횟수는 `deathsPvp` 로 따로 저장한다.

#### A (어시스트)

- 피해자가 죽기 전 **15초 안에** 피해를 준 다른 플레이어. 킬러는 제외.
- 사망 한 번에 한 사람당 한 번만.
- 최소 기여: 2.0 피해(하트 1칸) 이상 또는 피해자 최대 체력의 10% 이상. 툭 건드리고 어시스트를 챙기는 것을 막는다.
- 피해자와 같은 국가·동맹 국가 사람의 피해는 제외.
- 투사체·포션·늑대 피해도 소유자의 기여로 센다.

### 2. 표시

| 위치 | 표시 |
|---|---|
| `/info` 창 | `K 12   D 9   A 5   KDA 1.84`, `PvP 기준 KDA 3.40 (PvP 사망 5)`, 아군 사살 0 |
| 국가 GUI 국민 목록 | 머리 아이콘 설명에 K·KDA, 클릭하면 `/info` 창 |
| 디스코드 `/정보` | 같은 카드 |

#### PvP 기준 KDA 를 함께 보여 주는 이유

D 에 좀비·환경 사망이 모두 들어가면 KDA 는 PvP 실력보다 **생존력** 지표가 된다. 시뮬레이션(3주 시즌)에서 핵심 유저의 시즌 KDA 는 전체 사망 기준 0.5~0.7, PvP 사망만 셀 때 1.3~1.6 으로 두 배 이상 차이 났다(시즌 PvP 킬은 1인당 2회 안팎). 원래 정의대로 표시하되, 마우스를 올리면 PvP 기준 값도 보이게 한다. 설정 `kda.deaths = ALL | PVP` 로 표시 기준을 바꿀 수 있다.

### 3. 저장

`SavedData` `snw_players` 에 UUID 별로.

```json
{
  "uuid": "…",
  "kills": 12,
  "deaths": 9,
  "deathsPvp": 5,
  "assists": 5,
  "teamKills": 0,
  "recentVictims": { "<uuid>": [1736420000, 1736420300] },
  "log": [
    { "t": 1736420300, "type": "kill", "victim": "<uuid>", "assists": ["<uuid>"], "where": "overworld", "x": 812, "z": -340 }
  ]
}
```

- `log` 는 시즌 결산·분쟁 확인용 원장이다. 좌표는 운영자와 결산에만 쓰고 공개하지 않는다.
- 피해 기여 추적은 메모리에만 둔다(피해자별 최근 15초 피해 목록). 서버 재시작 중에 걸친 기여는 버린다.

### 4. 이벤트

K/D/A 가 바뀔 때 `snw-api` 이벤트(`onPlayerKill`)를 낸다. 디스코드 모드가 이를 받아 킬 피드를 보낸다. 킬 피드에는 좌표를 넣지 않는다.
