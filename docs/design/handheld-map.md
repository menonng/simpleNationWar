# 휴대 지도 (검토 중)

2026-11-21. 바닐라 클라이언트만으로 Xaero's 미니맵에 가장 가까운 것을 서버가 준다. 보조손에 든 바닐라 지도에 **서버가 그 사람 주변을 실시간으로 그린다.** 운영자 검토 뒤 넣을지 정한다.

## 1. 예시

예시 이미지는 대화로 전달했다. 다시 만들려면 [`tools/mapmock`](../../tools/mapmock)을 쓴다(실행하는 사람의 마인크래프트 jar 에서 지도 배경·아이콘을 읽는다. Mojang 텍스처가 들어가므로 이미지는 저장소에 넣지 않는다).

- 지형은 시험 월드(시드 20270116)의 실제 블록을, 게임 코드에서 뽑은 바닐라 지도 색(64색 × 밝기 4단계)과 바닐라 음영 규칙으로 그렸다. 실제 게임 지도와 같은 모습이다.
- **A. 기본**: 지형 + 국가 경계(자국 실선, 타국 점선) + 나(흰 화살표) + 근처 자국민(파란 표지) + 수도(국가 깃발) + 사망 지점(빨간 X, 본인만).
- **B. A + 감염 레벨 무늬**: 4×4 청크 칸마다 레벨 색 점무늬(Lv1~2 초록, Lv3~4 보라, Lv5 빨강).
- **C. 배치 개략도**: 보조손에 들었을 때의 대략적인 크기와 위치(실제 게임 화면이 아니다).

## 2. 규칙 (초안)

| 항목 | 내용 |
|---|---|
| 받는 법 | 바닐라로 만든 **빈 지도를 쓰면** 그 사람 전용 휴대 지도가 된다. 새 명령어 없음. 잃어버리면 다시 만든다 |
| 축척 | 1블록 = 1칸(128 × 128 블록). (제안) 웅크리고 쓰면 1:2(256블록)로 바꿈 |
| 중심 | 나. 지도 중심에서 16블록 넘게 벗어나면 지형을 다시 그린다 |
| 그리는 것 | 지표면만. 동굴 속·네더 천장 아래는 그리지 않는다(Xaero's '동굴 모드'를 끄는 것과 같은 공정성). 불러오지 않은 곳은 빈 종이 |
| 아이콘 | 나, 수도, 사망 지점(본인만), (선택) 근처 자국민. **적국 플레이어는 절대 그리지 않는다** |
| 색 | 바닐라 지도는 지도 색표 안의 색만 쓸 수 있다. 국가 색은 가장 가까운 지도 색으로(파랑 → 지도 파랑, 빨강 → 지도 빨강) |
| 다른 사람 | 지도 내용은 그 사람에게만 보낸다(같은 아이템을 남이 주워도 그 사람 기준으로 다시 그림) |

## 3. 부하 (추정, 측정 전)

- 아이콘(나·자국민)만 자주 갱신: 0.25초마다, 한 번에 수십 바이트.
- 지형 다시 그리기: 1회 16KB(128 × 128). 달리면 약 3초에 한 번 → 1인당 초당 5KB 안팎. 20명이면 업로드 약 100KB/s.
- 서버: 다시 그릴 때 1만 6천 칸의 높이·지도 색 조회. 불러온 청크만 읽고 결과를 청크 단위로 캐시한다. 20명 기준 평균 0.2ms/틱 미만(추정).

## 4. 제약

- 보조손을 차지한다(방패·불사의 토템과 동시에 못 든다). 주 손에 들면 화면 가운데에 크게 보인다.
- 크기 128 × 128 고정, 북쪽이 위로 고정(내 화살표가 돈다).
- Xaero's 처럼 화면 구석에 늘 떠 있게 하려면 리소스팩 코어 셰이더가 필요하다. 리소스팩 규칙(셰이더 없음)과 충돌해 쓰지 않는다.

## 5. 검토할 것

1. 넣을지 말지.
2. A(깔끔) 대 B(감염 무늬).
3. **자국민 아이콘**: 로케이터 바를 끈 취지가 '서로 위치를 덜 보이게'라면 빼는 게 맞다. 그러면 지도에는 나·수도·사망 지점만 남는다.
4. 축척 전환(웅크리고 쓰기) 여부.
