# Towns and Nations 분석

참고 대상: [Towns and Nations](https://modrinth.com/plugin/towns-nations) (Leralix, GPL-3.0-or-later, Paper/Spigot/Purpur, Vault·SphereLib 필요). 위키는 0.15.0(전쟁 업데이트) 이후 기준. 2026-11-19 조사.

> GPL-3.0 플러그인이므로 **코드는 가져오지 않고 설계만 참고**한다.

## 1. 원본 기능 요약

| 영역 | 원본 |
|---|---|
| 계층 | 마을(Town) → 지역(Region) → 국가(Nation). 마을·지역은 청크를 점령하고, 국가는 지역들의 연합(기본적으로 점령 불가) |
| 가입 | `/tan invite`, GUI 의 마을 목록에서 신청 |
| 점령 | `/tan claim`, `/tan unclaim`, `/tan autoclaim`, `/tan map`(청크 지도 GUI 에서 클릭으로 점령) |
| 유지비 | 청크 유지비가 매일 국고에서 빠지고, 못 내면 청크가 하나씩 풀린다 |
| 경제 | 영토마다 국고. 고정세(마을이 개인에게, 지역이 마을에게), 사유지 거래세, 기부, `/tan pay`. 지출은 유지비·직위 급여·상위 영토 생성 등. Vault 필요 |
| 직위 | 직위별 권한(초대, 세금, 점령 …)과 급여 |
| 관계 | 동맹, 불가침, 중립, 엠바고, 전쟁 + 종주국·속국. 악화는 즉시, 개선은 상호 동의. 관계별로 PvP·전쟁 참여·사유지 거래·영토 출입·휴전 기간을 설정 |
| 전쟁 | 적대 관계에서 선포. 목표: 정복(청크), 랜드마크 점령, 요새 점령, 복속, 해방. 공격은 예약 시간에 시작, 청크에 더 많이 서 있는 쪽이 점령(수비가 많으면 분쟁 상태). 점령 청크는 '점유' 상태. 요새가 반경 안 청크를 보호. 항복 또는 전 영토·요새 함락으로 종료. 관리자 승인 옵션 |
| 랜드마크 | 마을만 점령 가능, 매일 아이템 지급, 전쟁 목표 |
| 사유지 | 점령 청크 안 3D 구역을 개인에게 주거나 판매·임대 |
| 지도 | Dynmap·squaremap·BlueMap·Pl3xmap 애드온, DiscordSRV 애드온 |
| UI | 대부분 GUI. 플레이어 명령은 도움말·GUI·잔액·채팅 채널·소식·송금·스폰·점령 계열·초대 정도 |

## 2. 이 서버에 맞춘 대응

| 원본 | 판단 | simpleNationWar |
|---|---|---|
| 마을 → 지역 → 국가 3단 계층 | **단순화** | 국가 3개 고정, 국가가 곧 집단. 국가당 3~5명이라 하위 계층이 필요 없다 |
| 자유 창설·초대 | **변경** | 국가는 시즌 시작 전에 정해지고, 소속은 상호평가 기반 편성 → 합의 → 운영자 확정 |
| `/tan map` 청크 지도 GUI | **채택** | `/n` → 영토 지도. 클릭으로 점령·해제. `autoclaim` 은 뺀다 |
| 청크 유지비 | **제외** | 친구 서버에서 유지비는 숙제가 된다. 대신 영토 상한으로 조절 |
| Vault 경제·세금·급여 | **제외** | 경제 모드 없음. 국고는 화폐가 아니라 공용 창고(아이템) |
| 직위와 권한 | **단순화** | 원수·간부·국민 3단계, 권한 고정 |
| 관계 5종 + 종주·속국 | **단순화** | 중립·동맹·적대 3종. 3국 구도에서 2:1 고착을 막으려고 동맹은 1개까지 |
| 휴전 기간 | **채택** | 적대 해제 후 72시간 재적대 불가 |
| 전쟁 목표 5종 | **축소** | 거점(랜드마크) 탈취만. 청크 정복·복속 없음 |
| 존재 기반 점령, 수비 우세 시 분쟁 | **채택** | 거점전의 점령 규칙으로 그대로 |
| 예약된 공격 시간 | **채택** | 거점전은 정해진 시간대에만 |
| 요새 | **제외** | 영토는 상시 보호되므로 불필요 |
| 랜드마크 일일 보상 | **채택** | 거점: 매일 자원 + 영토 상한 + 연구 조건 |
| 사유지(3D 구역) | **제외** | 국가당 3~5명이라 국민끼리 구역 나눌 일이 적다. 필요하면 시즌 2 |
| 관리자 전쟁 승인 | **변형** | 거점전 시간 자체를 운영자가 관리 |
| 지도 애드온 | **내장** | BlueMap·squaremap 어댑터를 모드 안에 둔다 |
| DiscordSRV 애드온 | **대체** | 전용 디스코드 모드 + 봇 |
| 소식(newsletter) | **대체** | 디스코드 알림 채널 + 접속 시 1줄 요약 |
| 국가 채팅 채널 | **대체** | 바닐라 팀 채팅. 그냥 치는 채팅이 국가 채팅, 전체는 `/g` |

## 3. 새로 넣는 것 (원본에 없음)

- **좀비 모드 연동**: 영토 상한에 국가 좀비 스코어 보너스, 감염 레벨의 영역 판정 제공.
- **K/D/A 기록**과 `/info`.
- **커스텀 닉네임**(디스코드 등록) 표시.
- **로케이터 바 국가 필터**: 바닐라 로케이터 바에 같은 국가 국민만 보이게.
- **국가 프로젝트(치료제 연구)**: 비동기 납품형 국가 목표.
- **폭발·굴착 피해 자동 복구**(영토 안, 5분).
