# 생존일지

디스코드에 매일 아침 올라가는 서버 일지. 시간이 안 겹치는 친구끼리도 서로의 이야기를 보게 하는 것이 목적이다.

- 코드: [`diary/`](../../diary) 모듈 (순수 Kotlin, 마인크래프트·디스코드 의존 없음). 봇(`discord-bot` 브랜치)이 이 모듈을 불러 쓴다.
- **외부 AI 서비스를 쓰지 않는다.** 규칙 기반 로컬 생성기다. 게임 기록을 외부로 보내지 않고, 같은 입력이면 항상 같은 글이 나온다.
- 테스트 입력으로 만든 샘플은 `./gradlew :diary:test` 후 `diary/build/diary-samples.md` 에 생긴다.

## 1. 입력: 무엇을 기반으로 쓰나

모드가 이미 기록하는 **게임 안 사건**만 쓴다. 입력 모델([`Model.kt`](../../diary/src/main/kotlin/dev/menonng/snw/diary/Model.kt))에는 개인정보 칸이 아예 없다.

| 입력 | 형태 |
|---|---|
| 사람 | 커스텀 닉네임, 소속 국가, 일지 표시 동의, 웃긴 기록 동의, 불투명한 내부 키(디스코드 ID 해시) |
| 시각 | 새벽·아침·낮·저녁·밤 다섯 구간만 |
| 장소 | '1국 영토', '생존자 캠프', '북쪽 황야', 거점 이름, '감염 둥지 근처', 네더, 엔드 |
| 사건 | 좀비·사고 사망, PvP 킬·어시스트, 망자 회수·약탈, 알파 처치, 둥지 파괴, 블러드문, 거점 점령, 도감 달성, 8성 이상 강화, 백신 조각 |
| 서버 요약 | 감염도 전후, 국가별 좀비 스코어 합(1위만 언급), 보름달 횟수, 백신 조각 수 |

| 넣지 않는 것 | 이유 |
|---|---|
| 좌표 | 기지 위치 노출 |
| 정확한 시각, 접속·퇴장, 개인 플레이 시간 | 생활 패턴 노출 |
| 채팅·귓속말·전서구 내용 | 사적 대화 |
| 마크 이름, 디스코드 계정, IP | 일지에 필요 없음 |
| 상호평가, 가입 때 적은 접속 가능 시간 | 비공개로 받은 정보 |

### 이름 처리

- 일지 표시에 동의하지 않은 사람은 **'한 생존자'**, 여럿이면 '생존자 둘'처럼 쓴다.
- 닉네임이 개인정보 검사([nickname.md](../design/nickname.md) 3절)에서 거절 판정이면, 동의했더라도 익명으로 쓴다(이중 안전장치).
- 같은 사고를 되풀이한 기록(하루 두 번 낙사 등)은 **웃긴 기록에 동의한 사람만** 쓴다. 동의하지 않았으면 그 사건 자체를 뺀다.

## 2. 생성 과정

```
사건 목록 ─▶ ① 이야기 표지 ─▶ ② 묶기 ─▶ ③ 중요도 점수 ─▶ ④ 고르기(제약)
                                                          │
기억(지난 7일) ◀─────────────── ⑧ 기억 갱신 ◀─ ⑦ 전체 검사·재작성 ◀─ ⑥ 문장 고르기 ◀─ ⑤ 문단 계획
```

| 단계 | 하는 일 |
|---|---|
| ① 이야기 표지 | 되갚기(3일 안에 당한 상대를 되갚음), 맞수(같은 둘이 세 번 이상), 반복 사고, 서버 첫 사건, 자기 망자 회수 / 자국민이 대신 회수, 여럿이 함께, 오랜만의 블러드문 |
| ② 묶기 | 같은 구간의 좀비 사망 여럿 → 한 문장, 도감 여럿 → 한 문장, 같은 사람의 같은 사고 반복 → 한 사건 |
| ③ 중요도 | 종류별 기본 점수(블러드문 9, 알파 8, 망자 약탈·거점 7, PvP 6 …) + 이야기 가산(되갚기 +5, 서버 첫 사건 +3 …) + **며칠 동안 일지에 안 나온 사람 가산**(조명을 고르게) |
| ④ 고르기 | 최대 6건, 한 사람당 2건, 같은 종류 2건(아주 중요한 것은 예외) |
| ⑤ 문단 계획 | 여는 말(감염도 변화) → 새벽~낮 → 저녁~밤 → 블러드문 → 국가 소식·맺음말. 사건이 없는 날은 짧은 '조용한 하루' |
| ⑥ 문장 고르기 | 사건마다 목소리에 맞는 문장 틀을 **전부 채워 보고**, 벌점이 가장 낮은 것을 고른다. 벌점: 바로 앞 두 문장과 같은 첫 낱말·끝 낱말, 최근 이틀 안에 쓴 틀(+4), 나흘 안(+2), 오늘 이미 쓴 틀(+3), AI 상투어, 약간의 무작위 |
| ⑦ 전체 검사 | 완성된 글 전체를 다시 검사해서 벌점이 0 이 될 때까지 다른 난수로 최대 6번 다시 쓴다. 1,500자 넘으면 큰 벌점 |
| ⑧ 기억 | 사람은 내부 키로만, 문장 틀은 id 와 마지막 사용일로 저장. 닉네임은 기억하지 않는다 |

### 한국어 처리

- 조사는 앞 낱말의 받침으로 고른다: 은/는, 이/가, 을/를, 과/와, 으로/로(ㄹ 받침은 '로'), 이었다/였다, 이에요/예요.
- 숫자·영문으로 끝나는 닉네임은 읽는 소리로 판단한다(`하루2를`, `노을3을`, `Paul로`, `Sam이`).
- 목록은 `노을, 빗소리와 한 생존자` 처럼 잇는다.
- 공통 코드: `logic` 모듈의 `KoreanJosa`.

## 3. 목소리

| | 생존자 목소리 (`SURVIVOR`) | 관찰자 목소리 (`OBSERVER`) |
|---|---|---|
| 방향 | AI 티를 줄이는 쪽 | 차분한 관찰자, '클로드 느낌' |
| 어미 | 평서체 과거(-다) | 해요체 |
| 성격 | 짧고 구체적, 감탄 없음, 가끔 끊어 쓰는 문장 | 정확하고 다정함, 가끔 건조한 농담("러너는 정말 빨라요") |
| 예 | 노을이 북쪽 황야에서 러너에게 따라잡혔다. 짐은 무사했다. | 노을이 북쪽 황야에서 러너에게 따라잡혔어요. 러너는 정말 빨라요. |

설정에서 하나를 고른다. 문장 틀은 목소리마다 따로 쓴다(어미를 기계적으로 바꾸면 어색해서).

### AI 티를 줄이는 규칙 ([`Render.kt`](../../diary/src/main/kotlin/dev/menonng/snw/diary/Render.kt) `StyleLinter`)

- 금지 상투어: 흥미롭게도, 놀랍게도, 결론적으로, 요약하자면, 한편, 마치, 여정, 눈부신, 다양한, 중요한 것은, 물론, 그야말로, ~라고 할 수 있, 잊지 못할, 새로운 장, 서사, 역사적인, 이모지, 줄표(—), 말줄임표, 물결표
- 생존자 목소리는 느낌표 금지, 관찰자 목소리는 한 글에 하나까지
- 목소리 섞임 금지(평서체 글에 해요체, 해요체 글에 평서체)
- 쉼표 세 개 이상 나열 금지
- 이어지는 두 문장의 첫 낱말·끝 낱말이 같으면 벌점(문단을 넘어서도)
- 격언처럼 들리는 맺음 문장("~는 법이다") 대신 구체적인 사실 문장

## 4. 샘플 (테스트 입력, 생존자 목소리)

```
생존일지 · 2일째 (1월 17일)

감염도가 또 올랐다. 0.3에서 0.6으로.

새벽에 생존자 둘이 좀비에게 쓰러졌다. 노을은 오늘만 두 번 높은 데서 떨어졌다.

처음으로 사람끼리 칼을 맞댔다. 민준이 하늘을 쓰러뜨렸다.

좀비를 제일 많이 잡은 나라는 2국이었다. 내일은 감염도 0.6 근처에서 시작한다.
```

'생존자 둘'은 표시에 동의하지 않은 사람과 개인정보가 든 닉네임(`김민수2009`)이 익명 처리된 결과다.

## 5. 봇 연동

1. 매일 06:05, 봇이 전날 사건을 모드에게서 받은 이벤트 기록으로 [`DayInput`](../../diary/src/main/kotlin/dev/menonng/snw/diary/Model.kt) 을 만든다. 시각은 이때 `DayPart.ofHour` 로 뭉갠다.
2. `DiaryWriter(voice, salt).write(input, memory)` → 일지와 새 기억.
3. #생존일지 채널(생존자 역할만)에 올리고, 기억을 봇 DB 에 저장한다.
4. `salt` 는 서버마다 다른 값으로 설정 파일에 둔다(같은 날짜라도 서버마다 다른 문장).

## 6. 늘려 갈 것

- 문장 틀은 지금 사건 종류마다 1~3개. 시즌 전에 종류마다 5개 이상으로 늘린다.
- 틀을 코드 밖(JSON)으로 빼서 운영자가 고칠 수 있게.
- 주간 결산(일요일 아침): 일주일 이야기 표지를 모아 한 편.
