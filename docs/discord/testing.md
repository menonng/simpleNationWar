# 디스코드 시험 (혼자서)

운영자 한 명이 실제 디스코드 서버에서 상호평가·국가 추첨 흐름을 끝까지 보는 방법. 디스코드 계정을 여러 개 만들 수 없으니(약관), **가짜 멤버는 봇 DB 에만** 만든다. 가짜 멤버는 id 가 `test-` 로 시작하고 디스코드 계정이 없어 DM·역할은 건너뛴다. 버튼·모달·DM·공지는 운영자 본인 계정으로 실제 화면에서 확인한다.

### 1. 준비

1. **시험용 디스코드 서버**를 하나 만든다(실제 서버와 따로).
2. [디스코드 개발자 포털](https://discord.com/developers/applications)에서 애플리케이션 → Bot 을 만들고:
   - **Server Members Intent** 켜기(Message Content Intent 는 필요 없다).
   - 토큰을 복사해 **봇을 돌릴 컴퓨터의 환경 변수** `SNW_BOT_TOKEN` 에만 넣는다. 채팅·저장소에 붙이지 않는다.
3. OAuth2 → URL Generator: scope `bot`, `applications.commands`, 권한 *역할 관리·채널 관리·별명 관리·메시지 보내기·임베드 링크·채널 보기* → 나온 주소로 시험 서버에 초대.
   - 서버 설정 → 역할에서 **봇 역할을 맨 위 가까이** 올린다(아래 역할만 줄 수 있다).
4. 채널을 만든다: #등록 #공지 #운영진(최소). 디스코드 설정 → 고급 → 개발자 모드를 켜면 채널을 우클릭해 id 를 복사할 수 있다.
5. 시험용 설정 파일 `config-test.json`(봇 폴더, 저장소에 넣지 않는다):

```json
{
  "guildId": "시험 서버 id",
  "dbPath": "snw-bot-test.db",
  "testMode": true,
  "channels": { "register": "#등록 id", "notice": "#공지 id", "admin": "#운영진 id" }
}
```

6. 실행: `./gradlew :discord-bot:installDist` 후
   `SNW_BOT_TOKEN=… SNW_WS_SECRET=아무값 discord-bot/build/install/discord-bot/bin/discord-bot config-test.json`
   - 로그에 `시험 모드가 켜져 있습니다`, `슬래시 명령 N개 등록` 이 나오면 준비 끝. 마크 서버는 없어도 된다(게임 쪽은 연결되면 rating.info 를 받는다).
   - **DB 를 실제 시즌과 따로**(`snw-bot-test.db`) 둔다. 실제 시즌 설정에서는 `testMode` 를 끈다.

### 2. 시험 순서

| 단계 | 할 일 | 확인할 것 |
|---|---|---|
| 1 | `/테스트 나` → `/테스트 더미 수:11` | 참가자 12명 |
| 2 | `/평가 시작 마감시간:48` | 내 DM 에 [평가하기], #공지 안내 |
| 3 | DM [평가하기] → 모달 몇 번 | 라디오 그룹(⭐1~5·잘 모름)이 제대로 보이는지, '진행 n / 11'·[다음 사람] |
| 4 | `/평가 현황` | 이름과 진행 수만, 점수 없음 |
| 5 | `/테스트 평가채우기` | 더미들이 전원(나 포함) 평가 |
| 6 | `/테스트 마감당기기 분:2` | 30초 안에 (내가 덜 했으면) 독촉 DM, 2분 뒤 #운영진 '시간 만료로 마감' + 이상치 경고(더미01) |
| 7 | `/평가 결과 공개:true` | 내 DM 에 항목별 결과, #공지 항목별 상위 3명 |
| 8 | `/테스트 단짝` → `/테스트 팀장자동` | #공지 팀장 발표 |
| 9 | `/팀 추첨` | #공지 시드 해시 → 10초마다 한 명씩 → 시드·공개 입력. 단짝이 같이 나오는지 |
| 10 | `/테스트 목록` → `/테스트 교환 번호:n` | 다른 국가 더미와 맞교환(균형 기준을 넘으면 거절 문장) |
| 11 | `/팀 확정` | 1국·2국·3국 역할과 카테고리(#국가-채팅·#국가-알림·🔊국가-음성) 생성, 내 계정에 역할 |
| 12 | `/테스트 정리 국가채널:true` | 가짜 멤버·시험 기록·국가 역할·채널 삭제 |

부계정이 있으면 3단계를 부계정으로도 해 보고, #등록 의 [등록하기] 모달(텍스트 칸 5개)도 열어 본다. 실제 등록·연동은 마크 서버와 Mojang 조회가 필요해 `/테스트 나` 로 건너뛴다.

### 3. /테스트 명령

`testMode: true` 일 때만 생기고, 서버 관리 권한이 있어야 쓴다. 답은 나에게만 보인다.

| 명령 | 하는 일 |
|---|---|
| `나` | 나를 참가자로(게임 연동 없이, 닉네임 '테스터', 예상 시간 14h~). 이미 연동했으면 그대로 |
| `더미 [수]` | 가짜 멤버를 n 명까지 채운다(기본 11, 최대 20, 닉네임 더미01…, 예상 시간 무작위) |
| `평가채우기` | 열린 라운드에서 더미들이 모두를 평가(숨은 실력 + 흔들림, 15% 잘 모름). 더미01 은 한 사람에게 1점을 몰아줘 이상치 경고를 시험 |
| `마감당기기 [분]` | 마감을 n 분 뒤로(기본 2). 독촉 DM → 자동 마감 |
| `단짝` | 더미끼리 서로 지목한 두 쌍 |
| `팀장자동 [나포함]` | 예상 시간 상위 절반에서 팀장 3명(`/팀 팀장` 은 디스코드 유저만 고를 수 있어서) |
| `교환 번호` | 더미 n 번과 나의 맞교환(양쪽 신청을 한 번에) |
| `목록` | 더미와 국가 배정 |
| `정리 [국가채널]` | 더미와 그 평가·단짝, 시험으로 만든 내 참가 기록, 더미가 낀 추첨 상태를 지운다. `국가채널:true` 면 봇이 만든 국가 역할·카테고리·채널도 |

### 4. 정리

- `/테스트 정리` 는 평가 라운드 기록 자체는 남긴다. 깨끗이 하려면 봇을 끄고 `snw-bot-test.db` 를 지운다.
- `/팀 확정` 이 마크 서버에 연결된 상태였다면 게임 쪽 국가 배정도 갔다(가짜 멤버는 마크 UUID 가 없어 빠진다). 시험 서버에서만 한다.
